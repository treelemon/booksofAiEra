# 附录一：中国集成电路产业发展大事记（1956—2026）

| 年份 | 事件 | 意义 |
|------|------|------|
| 1956 | 四项紧急措施 | 中国半导体产业的起源 |
| 1960 | 中科院109厂成立 | 中国第一个半导体器件研制基地 |
| 1965 | 第一块集成电路 | 比世界首块晚7年 |
| 1972 | 第一块LSI PMOS电路 | 大规模集成电路起步 |
| 1978 | 首次引进生产线 | 从封闭到开放 |
| 1990 | 908工程 | 半导体产业化尝试 |
| 1996 | 909工程——华虹NEC 8英寸线 | 中国大陆首条8英寸线 |
| 2000 | 18号文件+中芯国际成立 | 政策与企业家共振 |
| 2004 | 海思半导体成立 | 华为"备胎计划" |
| 2014 | 国家大基金一期（￥1387亿） | 国家意志入场 |
| 2016 | 长江存储、长鑫存储成立 | 存储双雄起航 |
| 2019 | 实体清单+EDA断供 | 封锁开始升级 |
| 2020 | 台积电断供华为/中芯国际遭制裁 | 制造被"釜底抽薪" |
| 2022 | BIS新规+长江存储入实体清单 | 存储+AI芯片被封杀 |
| 2023 | 麒麟9000S回归（SMIC 7nm） | 逆袭第一弹 |
| 2024 | 大基金三期￥3440亿 | 总攻信号 |
| 2025 | 国产GPU四小龙上市 | AI算力新力量 |
| 2026 | 芯片年产量4842亿块/国产EDA全流程突破 | 规模初现、短板补位 |

*本年表随产业进展持续更新。*
