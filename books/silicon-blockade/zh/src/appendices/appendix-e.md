# 附录五：芯片产业专业名词解释

## 一、基础概念

| 名词 | 英文 | 解释 |
|------|------|------|
| 集成电路 | Integrated Circuit (IC) | 将晶体管、电阻、电容等元件集成在一块半导体晶片上的微型电路。俗称"芯片" |
| 半导体 | Semiconductor | 导电性能介于导体和绝缘体之间的材料（主要是硅）。芯片的物理载体 |
| 晶圆 | Wafer | 高纯度硅制成的圆形薄片，是制造芯片的"底板"。常见尺寸为8英寸（200mm）和12英寸（300mm） |
| 晶体管 | Transistor | 芯片中最基本的电子开关元件。一颗先进芯片上可以集成数百亿个晶体管 |
| 摩尔定律 | Moore's Law | Intel创始人戈登·摩尔1965年提出的观察——芯片上的晶体管数量大约每两年翻一番 |
| 制程节点 | Process Node | 芯片制造工艺的代际标识，如28nm、14nm、7nm、5nm、3nm。数字越小，晶体管越小，性能越强 |

## 二、产业链分工

| 名词 | 英文 | 解释 |
|------|------|------|
| IDM | Integrated Device Manufacturer | 垂直整合制造模式——一家公司同时完成芯片设计、制造、封装测试全部环节。代表：Intel、三星、长鑫存储 |
| Fabless | Fabless | 无晶圆厂模式——只做芯片设计，制造外包给晶圆代工厂。代表：英伟达、高通、华为海思、寒武纪 |
| Foundry | Foundry | 晶圆代工模式——只做芯片制造，不设计自己的芯片。代表：台积电、中芯国际、华虹半导体 |
| 封装测试 | Packaging & Testing | 将制造好的晶圆切割成单颗芯片，用外壳封装保护，并测试功能是否正常 |
| EDA | Electronic Design Automation | 电子设计自动化——芯片设计必须使用的工业软件。全球三巨头：Synopsys、Cadence、Mentor Graphics |
| IP核 | Intellectual Property Core | 芯片设计中可重复使用的功能模块（如CPU核、GPU核、接口控制器），可以授权给其他公司使用 |

## 三、核心设备与工艺

| 名词 | 英文 | 解释 |
|------|------|------|
| 光刻机 | Lithography Machine | 芯片制造最核心的设备。用紫外光将电路图案"刻"到晶圆上。一台高端EUV光刻机的价格超过$2亿 |
| EUV | Extreme Ultraviolet Lithography | 极紫外光刻——使用13.5nm波长的光，用于7nm及以下先进制程。全球只有荷兰ASML一家能生产 |
| DUV | Deep Ultraviolet Lithography | 深紫外光刻——使用193nm波长的光，用于28nm至7nm制程。中芯国际用DUV多重曝光实现等效7nm |
| 刻蚀机 | Etching Machine | 将光刻后暴露出来的不需要的材料"刻"掉。与光刻机并列为芯片制造两大核心设备 |
| 薄膜沉积 | Thin Film Deposition | 在晶圆表面沉积一层极薄的薄膜（如金属、绝缘体）。分为PVD（物理气相沉积）、CVD（化学气相沉积）、ALD（原子层沉积） |
| CMP | Chemical Mechanical Polishing | 化学机械抛光——将晶圆表面"磨平"，确保每一层电路都能精准对准。需要用到抛光液和抛光垫 |
| 良率 | Yield | 在一片晶圆上制造出的芯片中，功能正常的芯片所占的百分比。90%+为优秀。中芯国际7nm良率超90% |

## 四、芯片分类

| 名词 | 英文 | 解释 |
|------|------|------|
| CPU | Central Processing Unit | 中央处理器——计算机的"大脑"。代表：Intel酷睿、AMD锐龙、海光、龙芯、飞腾 |
| GPU | Graphics Processing Unit | 图形处理器/通用并行计算处理器。最初为游戏图形渲染设计，后来成为AI训练和推理的核心硬件。代表：英伟达H100/B200、AMD MI300X、寒武纪思元 |
| NPU | Neural Processing Unit | 神经网络处理器——专门为AI推理优化的芯片，用于手机和边缘设备 |
| ASIC | Application-Specific Integrated Circuit | 专用集成电路——为特定应用定制的芯片。比GPU更高效但灵活性差。代表：Google TPU、Amazon Trainium |
| FPGA | Field-Programmable Gate Array | 现场可编程门阵列——用户可自己编程的"半成品"芯片，灵活但成本高 |
| SoC | System on Chip | 片上系统——将CPU、GPU、NPU、内存控制器、通信基带等全部集成在一颗芯片上。代表：苹果A系列、华为麒麟、高通骁龙 |
| MCU | Microcontroller Unit | 微控制器——用于嵌入式系统和物联网设备的"小CPU" |
| IGBT | Insulated Gate Bipolar Transistor | 绝缘栅双极型晶体管——功率半导体核心器件，用于新能源汽车、高铁、电网等高压场景 |
| SiC | Silicon Carbide | 碳化硅——第三代半导体材料，用于高压、高温、高频场景（如电动车主驱逆变器），性能优于传统硅基芯片 |

## 五、存储芯片

| 名词 | 英文 | 解释 |
|------|------|------|
| DRAM | Dynamic Random Access Memory | 动态随机存取存储器——电脑和手机的"内存"。断电后数据消失。代表：三星、SK海力士、美光、长鑫存储 |
| NAND Flash | NAND Flash Memory | 闪存——手机和SSD固态硬盘的"存储"。断电后数据不消失。代表：三星、SK海力士、铠侠、长江存储 |
| HBM | High Bandwidth Memory | 高带宽存储器——通过3D堆叠技术将多层DRAM垂直连接，带宽比传统DRAM高10倍+。AI GPU的关键配套芯片。代表：SK海力士、三星、美光 |
| NOR Flash | NOR Flash | 另一种闪存，容量小但读取速度快，常用于嵌入式系统和IoT设备 |
| 3D NAND | 3D NAND | 通过垂直堆叠存储单元层来提高存储密度的NAND技术。层数越高，存储密度越大。长江存储232层/294层 |

## 六、先进封装与互联

| 名词 | 英文 | 解释 |
|------|------|------|
| 先进封装 | Advanced Packaging | 将多颗芯片（可能来自不同制程、不同厂商）通过高密度互联集成在一个封装体内的技术 |
| CoWoS | Chip-on-Wafer-on-Substrate | 台积电的2.5D先进封装技术——将GPU/CPU和HBM内存通过硅中介层连接。AI GPU出货的物理瓶颈 |
| Chiplet | Chiplet（芯粒） | 将一颗大芯片拆分为多颗小"芯粒"分别制造，再用先进封装集成为一个整体的技术。中国绕过先进制程限制的重要路径 |
| 2.5D封装 | 2.5D Packaging | 通过硅中介层将多颗芯片并排互联 |
| 3D封装 | 3D Packaging | 将多颗芯片垂直堆叠互联——HBM采用此技术 |
| 混合键合 | Hybrid Bonding | 直接将两片晶圆的铜触点对接键合——比传统的微凸块互联密度更高、延迟更低。长江存储Xtacking架构的核心技术 |

## 七、行业关键术语

| 名词 | 英文 | 解释 |
|------|------|------|
| 产能利用率 | Capacity Utilization Rate | 晶圆厂实际产出与满负荷产能的比率。中芯国际2026年Q1为93.1%，华虹半导体为99.7% |
| 月产能 | Monthly Capacity | 晶圆厂每个月能处理多少片晶圆。中芯国际2026年Q1月产能为107.8万片（折合8英寸） |
| 晶圆代工 | Wafer Foundry | 只做芯片制造、不做芯片设计、不卖自己品牌的芯片。台积电是这一模式的全球发明者 |
| 自主可控 | Independent and Controllable | 中国产业政策的核心目标——在关键环节摆脱对国外技术和供应链的依赖 |
| 国产替代 | Domestic Substitution | 用中国本土企业的产品替代进口产品。2019年制裁后从"可选项"变为"必选项" |
| 内卷化 | Involution | 产业在低水平、同质化的竞争中过度消耗，技术进步缓慢但价格战激烈 |
| 实体清单 | Entity List | 美国商务部工业与安全局（BIS）的出口管制名单。被列入的企业无法获得美国技术、软件和设备的出口许可 |
| 瓦森纳协定 | Wassenaar Arrangement | 1996年签署的多边出口管制协议。对常规武器和两用技术（含芯片）的出口施加限制。中国是主要受限对象 |

## 八、中国芯片产业特有名词

| 名词 | 解释 |
|------|------|
| 大基金 | 国家集成电路产业投资基金。一期￥1387亿（2014）、二期￥2042亿（2019）、三期￥3440亿（2024）。中国芯片产业最大的"金主" |
| 18号文件 | 2000年国务院《鼓励软件产业和集成电路产业发展的若干政策》。中国首次系统化支持IC产业 |
| 909工程 | 1996年启动的集成电路专项工程。建成了中国大陆首条8英寸生产线（上海华虹NEC） |
| 两长一大 | 长江存储（NAND Flash）+长鑫存储（DRAM）+大普微（SSD主控）——中国存储芯片的"国家队" |
| Xtacking | 长江存储自主发明的3D NAND架构——将存储阵列和逻辑电路分开制造再用混合键合集成的技术路径 |
| 韬定律（τ定律） | 华为提出的以"时间缩微"替代"几何缩微"的新技术发展范式——在制程受限的条件下，通过架构和算法创新持续提升性能 |
| "缺芯少魂" | 指中国信息产业的短板——"芯"指芯片，"魂"指操作系统。始于1999年倪光南院士的呼吁，此后成为中国信息产业的经典比喻 |
