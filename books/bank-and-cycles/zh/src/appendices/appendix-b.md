# 附录B：案例写作统一模板

全书10个典型案例分布于各章，每个案例遵循以下五段式标准结构，确保可比性和一致性。

## 模板结构

```
### 【专题案例研究】银行名称——一句话核心主题

> 一句话概括本案例的核心启示。

#### 1. 银行档案
- 成立时间：
- 历史沿革：
- 核心业务与定位：
- 关键规模指标（资产、利润、市值等，标注时间）：

#### 2. 关键挑战
- 遭遇了什么周期考验？
- 周期冲击的具体表现是什么？
- 当时面临的核心矛盾是什么？

#### 3. 应对策略
- 做了什么具体决策和动作？（列出3--5条）
- 决策背后的逻辑是什么？

#### 4. 结果对比
- 关键数据的前后变化（表格呈现）

| 指标 | 危机前 | 危机中 | 危机后 |
|------|-------|-------|-------|
| xxx | | | |
| xxx | | | |

#### 5. 启示提炼（不超过3条）
- 与所在章主题呼应的核心启示
- 可迁移的底层逻辑
```

## 使用说明

- 正面案例侧重提炼可复制的成功经验
- 反面案例（硅谷银行）侧重揭示不可逾越的底线
- 正反结合案例（日本新生银行）兼顾教训与变革经验
- 每条启示必须与所在章的理论框架或管理启示形成呼应
