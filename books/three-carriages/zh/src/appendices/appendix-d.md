# 附录D：写作说明

## 写作顺序

本书建议按以下顺序推进：

1. **第一阶段（故事锚点）**：序章和第7章（招行×智谱AI案例）起步，用故事和案例抓牢读者
2. **第二阶段（周期根基）**：第1章（低利率周期）、第5章（产业周期）、第9章（货币周期），奠定三个赛道的周期逻辑基础
3. **第三阶段（标杆对标）**：第3章（财富管理标杆）、第6章（科技金融标杆）、第10章（跨境金融标杆）、第11章（香港登顶）、第13章（全球银行业格局）、第14章（三大战略路径）
4. **第四阶段（深化应用）**：第2章（客户需求）、第4章（AI×财富管理）、第8章（金融科技）、第12章（跨境支付）、第15章（外资银行）
5. **第五阶段（周期共振）**：第16章（六期叠加）、第17—19章（三大共振区）
6. **第六阶段（收尾）**：引言 → 结语 → 附录

## 写作风格

- **叙述者视角**：全书用"我们"（行业观察者视角）统一叙述
- **核心章（★★★）**：故事+数据+分析三线并行，~8000字
- **支撑章（★★）**：结论+图表为主，~5000字
- **序章**：~3000字，结语~3000字
- **全书预计**：10—12万字
- **每章尾固定输出**：核心发现 + 银行管理启示
- **每章尾固定输出**：本章参考资料（含可点击的URL）

## 案例写作统一模板

每篇案例研究遵循三要素结构：

1. **挑战与背景**：遇到了什么周期/战略考验
2. **关键决策与行动**：做了什么
3. **启示与可迁移逻辑**：对中国银行业意味着什么（不超过3条）

## 章节结构统一模板

每章包含以下元素（按顺序）：

1. 章节标题（含★★★/★★重要度标注）
2. 灵魂说明（锚 + 一句话核心洞察）
3. 开篇段落
4. 小节（使用 X.X 格式编号）
5. 必要的表格数据
6. 本章参考资料（含可点击URL）
7. 核心发现 + 银行管理启示
