# 附录C："周期×赛道"战略决策矩阵

> 将三大赛道置于六重周期坐标系中的完整战略定位图。详见表16.3，此处为摘要速查版。

## 周期×赛道星级分布

| | 财富管理 | 科技金融 | 跨境金融 |
|---|---------|---------|---------|
| 宏观经济周期↓ | ★★★ 息差承压→中收突围 | ★★ 规模扩张空间收窄 | ★ 放缓但方向不变 |
| 利率周期↓ | ★★★ 存款搬家直接利好 | ★★ 降低科技企业融资成本 | ★ 间接利好 |
| 技术周期↑ | ★★★ AI投顾+智能配置 | ★★★ AI+赛道研究能力升级 | ★★ CIPS+区块链 |
| 产业周期↑ | ★ 高净值群体扩张 | ★★★ 科技企业信贷需求爆发 | ★★ 出海企业跨境需求 |
| 货币周期↑ | ★★ 跨境财富管理爆发 | ★ 海外融资便利 | ★★★ 人民币国际化受益 |
| 监管周期→ | ★ "五篇大文章"覆盖 | ★★★ 科技金融政策首位 | ★ 跨境监管规范化 |

★★★ = 周期与赛道高度共振，确定性最强
★★ = 明显共振，确定性较强
★ = 存在关联，共振强度较弱

## 三大共振区（★★★叠加热区）

| 共振区 | 共振周期 | 商业逻辑 | 典型先行者 |
|-------|---------|---------|----------|
| 科技×财富 | 利率↓ + 技术↑ | AI降低成本 → 覆盖更多客户 → AUM增长 → 数据反哺AI | 招行（AI财富管家） |
| 财富×跨境 | 利率↓ + 货币↑ | 低利率挤出境内配置 → 人民币国际化打开境外通道 | 汇丰（亚洲跨境财富） |
| 科技×跨境 | 技术↑ + 货币↑ | CIPS数字化 + 区块链贸易融资 + 数字人民币跨境 | 星展（CIPS卡位） |
