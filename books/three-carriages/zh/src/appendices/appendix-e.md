# 附录E：从业者周期行动自查清单

> 将全书的核心建议转化为可勾选的自查清单，供银行从业者在战略规划、年中复盘时使用。

## 一、周期判断篇

- [ ] 我已清楚六大周期（宏观/利率/技术/产业/货币/监管）当前所处的阶段和方向
- [ ] 我已完成"周期×赛道"矩阵的星级评估，知道贵行的★★★共振区在哪
- [ ] 我知道贵行最重要的2—3个周期变量是什么（例如：净息差、AI渗透率、人民币国际化指数）
- [ ] 过去12个月内，至少完成过一次周期扫描和战略校准

**关键参考指标**：
- 净息差 < 1.5% → 财富管理优先级升至最高
- 科技贷款增速 > 20% → 科技金融进入规模爆发放量期，需加速布局
- CIPS日均交易规模环比增速 > 30% → 跨境金融窗口正在打开

## 二、财富管理篇

- [ ] 已明确"存款立行"→"AUM立行"的转型时间表和关键里程碑
- [ ] 非息收入占比在过去一年有实质性提升（不是口号式目标）
- [ ] 已建立或正在建立客户生命周期分层服务体系（储蓄期/增值期/配置期/传承期）
- [ ] AI投顾或智能配置工具已覆盖核心客户群体（哪怕初期只有几十万客户）
- [ ] 养老金融产品货架已初步建设（这是财富管理与时间做朋友的最佳入口）

**关键参考指标**：
- 代理业务收入增速 > 15% → 财富管理转型正在加速
- AI财富管家客户覆盖率 > 20% → 飞轮已初步启动
- AUM增速持续 > 存款增速 → 转型初见成效

## 三、科技金融篇

- [ ] 已建立分赛道的行业研究能力（AI/半导体/新能源/生物医药等）
- [ ] 科技企业信用评估已引入"看未来"维度（技术壁垒+团队能力+赛道空间）
- [ ] 科技金融有独立的审批-考核-风险闭环（不以传统对公信贷的模板套用）
- [ ] 考核周期已从1年延长至3年或更长（否则"陪伴式服务"不可能落地）
- [ ] 已参与科技园区或孵化器的生态建设（不是为了宣传，是为了"种子期"卡位）

**关键参考指标**：
- 科技贷款增速 > 全行贷款增速 → 信贷结构正从"砖头"向"专利"迁移
- "小巨人"企业覆盖率 > 50% → 科技金融客户质量进入行业前列

## 四、跨境金融篇

- [ ] 已取得或正在申请CIPS直接参与资格（基础设施卡位）
- [ ] 已取得或正在规划香港财富管理相关牌照（有牌照才有资格进入跨境财富管理主战场）
- [ ] "跨境理财通"线上化率 > 80%（开户速度即竞争力）
- [ ] 已建立"服务中资企业出海"的专项服务团队或产品线
- [ ] 已参与数字人民币跨境试点或在试点申请筹备中

**关键参考指标**：
- 跨境业务中收占比在过去一年有所提升 → 跨境金融正从附属业务升级为利润贡献者
- 跨境理财通开户时间 < 1天 → 达到行业领先水平
- 覆盖的CIPS间接参与者数量持续增长 → 清算枢纽地位强化

## 五、科技赋能篇

- [ ] IT支出/营收比 > 5%（向8%—12%的国际标杆靠拢）
- [ ] 每一项技术投入绑定了明确的、可量化的业务效率指标（降本X%或提效Y倍）
- [ ] 核心AI能力为自研或深度定制（非纯外包采购，"AI盒子"通常只有加法级收益）
- [ ] 已为量子计算和隐私计算预留技术储备预算（哪怕只占科技预算的2%—5%）

**关键参考指标**：
- IT支出/营收比 < 4% → 你正在吃技术老本
- 自研AI应用的业务覆盖率 > 30% → 技术能力正从"买来的"变成"自己的"

## 六、路径选择篇

- [ ] 我能在一分钟内说清楚"我们银行最不可替代的能力是什么"
- [ ] 这个答案不超过三个要点
- [ ] 过去一年的重大战略决策与这个答案方向一致（没有被"风口"牵着走）
- [ ] 我已明确——我们走的是摩根大通式"加法乘法"、汇丰式"聚焦"、还是花旗式"减法重构"？还是三不像？

**危险信号（自查警告）**：
- 战略PPT上"同时发力五个方向" → 战略等同于愿望清单
- 预算分配在所有赛道上"均匀分布" → 没有任何一个方向能建壁垒
- 去年说"要做财富管理"，今年说"要做科技金融"，明年说"要做跨境" → 每一件事都做不深

---

> **使用说明**：建议在年度战略规划研讨会前，核心管理层每人独立完成自查；在战略研讨会上对照结果，发现认知不一致的领域——这些区域往往是最大的战略风险源。
